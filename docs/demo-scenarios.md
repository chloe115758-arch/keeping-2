# 시연·측정용 조합 (미리 알아 두고 쓰는 시나리오)

앱에서 **어떤 약과 영양제를 어떤 시각에 담으면 어떤 안내가 나오는지** 엔진으로 돌려 확인한 것이에요(`js/care.js` + `js/homevm.js`, 실제 병용금기 데이터).
아래 "화면에 나오는 것"은 코드가 만든 문장 그대로예요. 시각은 **담기 확인 화면의 시각 입력 칸**에 직접 쳐서 맞추세요.

> 신뢰 수준: **S1**(레보티록신+칼슘)은 허가사항 원문과 대조한 데이터이고, **S3**(시바스+이트라코나졸)는 공식 병용금기 데이터예요. S2·S4는 앱에 실제로 들어 있는 허가사항 묶음(성분 약 990개)에 따라 문장이 달라질 수 있으니 **앱에서 한 번 직접 확인**하고 쓰세요.

## S1. 간격 안내 + 시각 힌트 (발표 시연에 가장 좋아요)
| 담을 것 | 시각 |
|---|---|
| 씬지로이드정 (진료과 내과) | 07:00 |
| 칼슘 영양제 (영양제 검색 "칼슘") | 09:00 |

- 아침약 카드: `약 2개 · 주의 1`
- 칼슘 영양제 줄 아래 빨간 한 줄: **오전 11시 이후 섭취 권장**
- 주의 블록: **칼슘 영양제는 내과 처방약과 최소 4시간 간격을 두는 것을 권장해요**
- 블록을 누르면 근거 시트: **설명서에 이렇게 나와 있어요** + 허가사항 원문 + "이 안내가 가리키는 약"
- 주의 블록 아래 **"시간을 옮길까요?"** 제안: 설명서에 최소 4시간 간격 안내가 있어요. 칼슘 영양제를 오전 11시로 옮기면 안내된 간격을 지킬 수 있어요. [11:00으로 옮기기] [그대로 두기]
- **[11:00으로 옮기기]**를 누르면 칼슘이 점심 시간대로 옮겨 가고, 아침 카드에는 **"확인한 범위에서 찾은 주의가 없어요"**가 나와요. (앱은 사용자가 누를 때만 시간을 바꿔요.)
- 같은 약을 담되 칼슘을 **12:00**으로 하면 주의 블록이 사라지고 **"확인한 범위에서 찾은 주의가 없어요"**가 나와요(간격 4시간 이상). → "주의가 없을 때도 말한다"를 보여 주기 좋아요.

## S2. 여러 건이 겹칠 때 (외 N건)
| 담을 것 | 시각 |
|---|---|
| 씬지로이드정 (내과), 넥시움정20 (피부과) | 07:00, 07:30 |
| 알마겔에프 (약국약) | 08:00 |
| 칼슘 영양제 | 09:00 |

- 아침약 카드: `약 4개 · 주의 3`
- 주의 블록에 문장이 여러 개 나오고 2건까지만 보여요(나머지는 "외 N건").
- 숫자가 있는 안내는 "권장해요", 숫자가 없는 안내는 **"함께 쓸 때 주의가 필요하다고 안내돼 있어요"**로 말이 달라요.

## S3. 공식 병용금기 (가장 무거운 안내)
| 담을 것 | 시각 |
|---|---|
| 시바스정 (내과), 이트코나졸캡슐 (피부과) | 둘 다 21:00 |

- 자기 전 카드: `약 2개 · 주의 1`
- 주의 블록: **피부과 처방약은 내과 처방약과 함께 복용하지 않도록 지정된 조합이에요**
- 근거 시트 첫 줄: **공식 자료에 이렇게 나와 있어요** + "병용금기로 지정된 조합" + (있으면) "조건 · …" 줄

## S4. 주의가 없는 경우 + 조심할 음식
| 담을 것 | 시각 |
|---|---|
| 메토폴정 (내과) 하나만 | 12:30 |

- 점심약 카드 아래: **확인한 범위에서 찾은 주의가 없어요** / 공식 자료(병용금기·약 설명서)에서 찾아본 결과예요
- "내과 처방약" 줄을 눌러 약봉투 화면에 가면 **같이 조심할 음식: 알코올**이 나와요.

## 측정용 약 목록 (제안)
- **목록 A**: S2와 같은 4개 (간격 1건 + 주의 여러 건)
- **목록 B**: S3의 2개 + 메토폴정 (공식 병용금기 1건 + 음식 안내)
- 정답표는 **앱에 넣어 나온 안내를 근거 시트의 "원문 보기"와 대조해서** 확정하세요(앱 결과를 그대로 정답으로 삼지 않기).

## 시연 순서 (3분)
1. S1을 담는다 → 홈에서 주의 블록과 "오전 11시 이후" 힌트
2. 주의 블록을 눌러 근거 시트(원문, 출처, 확인일)
3. 칼슘 시각을 12:00으로 고친다 → "확인한 범위에서 찾은 주의가 없어요"
4. 마지막으로 S3 → 공식 지정 안내
