# 키핑 홈 헤더 UX 라이팅 (초안)

헤더의 **인사말**, **오늘의 복약 카드**(진행 바), **돌아보기 안내**가 **시간대와 복약 상태**에 따라 바뀌어요.
선생님은 아래 표의 **`내 문구`** 칸만 고치면 돼요. 코드는 열지 않아도 돼요.

ACTIVE_TONE: 친근

> 위 줄을 `기본`으로 바꾸면 담백한 말투, `친근`이면 말을 건네는 말투예요. `내 문구`가 적힌 줄은 어느 말투든 `내 문구`가 우선이에요.

## 사용법
1. 표의 `내 문구` 칸에 바꿀 문구를 적어요(비우면 선택한 말투가 쓰여요).
2. 터미널: `python3 scripts/apply_copy.py` — 금지 표현이 있으면 ⚠가 떠요.
3. 앱이 `data/copy/greeting.json`을 읽어서 반영해요.

## 변수 (문구 안에 쓸 수 있는 것)
`{name}` 이름(별명) · `{taken}` 확인한 칸 수 · `{left}` 남은 칸 수 · `{total}` 오늘 전체 칸 수 · `{missed}` 놓친 시간대("아침", "아침·점심") · `{missedN}` 놓친 칸 수 · `{subject}`·`{object}` 주의 문장의 두 쪽 · `{interval}` 간격("최소 4시간 간격") · `{time}` 시각("오전 11시") · `{verb}` 섭취/복용 · `{dept}` 진료과 · `{c}` 주의 개수 · `{more}` 더 있는 건수 · `{note}` 공식 병용금기의 조건(비고)

조사는 **`{subject:은/는}`처럼 `|` 뒤에 쓰면** 받침에 맞게 자동으로 붙어요(은/는, 과/와, 을/를, 이/가, 으로/로).

`{name}`은 **이름이 없으면 앞뒤 쉼표와 "님"까지 같이 사라져요.** 예) "좋은 아침이에요, {name}님!" → 이름이 없으면 "좋은 아침이에요!"

## 시간대와 상태
| 시간대 | 시각 |
|---|---|
| 아침 | 04:00 ~ 10:59 |
| 점심 | 11:00 ~ 14:59 |
| 저녁 | 15:00 ~ 20:59 |
| 밤 | 21:00 ~ 03:59 |

| 우선순위 | 상태 | 조건 |
|---|---|---|
| 1 | 비어 있음 | 시간을 정한 약이 하나도 없음 |
| 2 | 모두 마무리 | 오늘 시간대가 전부 "확인함" 또는 "건너뜀" |
| 3 | **놓친 시간대 있음** | 시간이 지났는데(+60분) 아직 체크 안 한 시간대가 있음 |
| 4 | 진행 중 | 확인한 개수가 1개 이상 |
| 5 | 시작 전 | 확인한 개수가 0 |

## 문구 원칙 (이 서비스에서는 이게 중요해요)
- **복용 지시를 하지 않아요.** "드세요", "챙겨 드세요", "복용하세요"는 쓰지 않아요. 앱은 **확인·돌아보기**를 권해요. 놓친 약을 언제 어떻게 할지는 약마다 달라서 근거 없이 말하지 않아요.
- **죄책감을 주지 않아요.** "못 했어요", "안 드셨어요" 대신 "아직 체크되지 않았어요".
- **"괜찮아요", "안전해요"는 쓰지 않아요.** 위로가 안전하다는 말로 읽혀요. 위로가 필요하면 "기록해 둘게요" 같은 행동 문장으로.
- 짧게(한 줄 20자 안팎), 숫자는 구체적으로, 해요체.

## 상호작용 규칙
1. **체크 칸 = 묶음 하나**예요. 처방약은 진료과별 묶음("내과 처방약"), 약국약은 "약국약" 하나, 영양제는 **이름 그대로 한 줄씩**이에요. 칸을 누르면 체크, 한 번 더 누르면 해제예요(누르는 영역 44px 이상). **건너뜀 상태는 없어요**(체크하지 않으면 그냥 먹지 않은 것).
2. **진행 바 = 체크한 칸 / 오늘 전체 칸.** 시간대 카드의 "약 3개"는 실제 약 개수이고, 바의 숫자는 체크 칸 개수예요. 시간을 정하지 않은 약은 홈에서 제외해요.
3. 바는 **0.3초** 동안 차오르고(움직임 줄이기 설정이면 즉시), 숫자와 한 줄 문구가 같이 바뀌어요. 스크린리더에는 "7개 중 3개 확인했어요"라고 읽어 줘요.
4. **놓친 시간대**(시간대가 지나고 60분 뒤에도 체크 안 함)가 있으면 인사말 둘째 줄이 바뀌어요. **버튼은 없고**, "아래에서 확인해 볼까요?"처럼 타임라인을 가리켜요.
5. **주의 블록**은 시간대 카드 맨 아래에 하나, 안내는 최대 2건, 넘으면 "외 N건". 한 건을 누르면 근거 시트가 올라와요. "권장해요"는 **설명서에 간격 숫자가 있을 때만** 써요. 숫자가 없으면 "주의가 필요하다고 안내돼 있어요", 공식 병용금기는 "지정된 조합이에요".
6. **묶음 줄을 누르면** 그 묶음의 약을 약봉투처럼 보여 주는 화면으로 가요. 조심할 음식은 여기에 모아요(홈에는 두지 않아요).
7. 시간대 이동은 앱을 열어 둔 채로도 1분마다 다시 계산하고, 앱으로 돌아올 때도 다시 계산해요.
8. 확인한 기록은 **오늘 하루만**, 이 기기에만 저장해요(자정에 새로 시작).

## 이름(별명)
- 온보딩에서 **"어떻게 불러 드릴까요?"**를 **선택 사항**으로 한 줄만 받아요(건너뛰기 가능). 이름은 이 기기에만 저장해요.
- 비워 두면 이름 없이 인사해요.
