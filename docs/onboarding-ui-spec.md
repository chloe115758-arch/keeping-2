# 온보딩 화면 구현 설명서 (시안 그대로)

시안은 `docs/design-ref/onboarding/`의 이미지 8장이다. **402×874, 1배**라서 이미지의 픽셀 좌표가 그대로 CSS px이다. 아래 숫자는 이미지를 직접 재서 뽑은 값이다.
**비교는 눈이 아니라 숫자로 한다:** 화면마다 `tests/ui-diff.py`로 시안과 앱 스크린샷의 일치율을 재고, 97% 미만이면 차이 이미지를 보고 고친다(6장).

## 0. 지킬 것
1. **화면 디자인과 UX 라이팅은 바꾸거나 더하지 않는다.** 글자는 시안 이미지에 적힌 그대로(줄바꿈, 띄어쓰기 포함). 시안에 없는 안내·버튼·설명을 만들지 않는다. 시안과 다르게 해야 하는 곳은 **7장 목록의 것만**이고, 그 밖에서 어긋나면 고치지 말고 보고한다.
2. **스플래시 → 환영 전환은 3초 인터랙션**이다(큰 로고가 위쪽 작은 로고로 합쳐진다, 3장).
3. **복약 등록에서 아침·점심·저녁을 고르면 시간 설정은 바텀시트**다(4-6장). 약 등록과 영양제 등록 모두에 쓴다(기존의 시간 아코디언은 이것으로 교체).
4. 새 문구가 꼭 필요하면 이미 `data/copy/greeting.json`에 있는 것(`time_invalid`, `time_band_hint`, `toast_taken` 등)만 쓰고, 그 밖의 새 문구는 쓰지 말고 보고한다.

흐름: 스플래시 → 환영 → 약관 동의 → 복약 정보 검색 → (결과 줄 선택 → **다음**) → 복용법 입력 → **저장** → 복약 정보 검색(이어서 더 담기) → **다음** → (기존 다음 단계) → 홈.
- 환영은 `history`의 **첫 화면**이다. 스플래시는 history에 넣지 않는다(뒤로 가기로 돌아오지 않는다). 환영에서 뒤로 가기는 앱을 떠난다.

- 시안에 없는 화면(영양제 등록, 시간 정하기 외의 단계, 홈 등)은 **지금 앱 그대로 두고**, 아래 공통 값만 맞춘다.

## 3. 스플래시 (01) 와 3초 전환
**정지 화면(01):** 배경 `--kp-splash-bg` 전체. 가운데에 한 줄 글 **"처방전 해석부터 건강 관리까지"**(14px, `--kp-tagline`, 가로 가운데, y=395~409) 바로 아래 큰 로고 **"Keeping"**(가로 187px × 세로 52px, `--kp-logo-splash`, x=108~294, y=431~482). 글과 로고 사이 22px.
**로고 파일:** `assets/brand/keeping-logo.svg`(선생님이 피그마에서 내보낸 SVG, 글자를 도형으로 바꾼 것)를 인라인 SVG로 쓴다. 없으면 임시로 "Keeping" 글자(Pretendard 700)를 쓰고 보고한다. **두 로고는 같은 한 개의 요소**여야 한다(아래 전환).

**환영의 작은 로고(02):** 가로 59px × 세로 16px, x=41, y=114~129, 색 `--kp-brand-ink`.

**3초 타임라인(전체 3.0초):**
| 시간 | 일어나는 일 |
|---|---|
| 0 ~ 0.4초 | 큰 로고와 한 줄 글이 서서히 나타남(opacity 0→1) |
| 0.4 ~ 1.4초 | 정지(시안 01 그대로) |
| 1.4 ~ 2.4초 | **큰 로고가 작은 로고 자리로 이동하며 줄어든다**: 위치 (108,431) → (41,114), 크기 ×1(187px) → ×0.316(59px), 색 `#35B89A` → `#239B80`. 동시에 한 줄 글은 사라지고(opacity 1→0, 0.4초), 배경은 `#F3FFFC` → `#FFFFFF`로 바뀜. 곡선 `cubic-bezier(0.4, 0, 0.2, 1)` |
| 2.4 ~ 3.0초 | 환영의 제목·본문·버튼이 아래에서 8px 올라오며 나타남(opacity, translateY 8→0, 0.6초, 항목마다 80ms 간격) |
- **같은 로고 요소를 움직인다**(큰 것을 지우고 작은 것을 새로 그리지 않는다). 환영 화면을 미리 그려 두고 작은 로고의 자리(`getBoundingClientRect`)를 재서 `transform: translate()` + `scale()`로 보낸다(FLIP). **`document.fonts.ready` 뒤에** 재서 글자 폭이 바뀌어도 어긋나지 않게 한다.
- 움직이는 것은 `transform`과 `opacity`만(Safari 렌더링 규칙). 큰 로고 층은 `position: fixed`, `will-change: transform`, 끝나면 `will-change` 해제.
- `prefers-reduced-motion: reduce`이면 정지 화면 1초 후 환영으로 바로 바뀐다(애니메이션 없음).
- 3초 중 아무 곳이나 눌러도 건너뛰지 않는다(시안에 건너뛰기가 없다).

## 4. 화면별 명세 (좌표는 시안 기준)
### 4-1. 환영 (02)
- 작은 로고(위), 제목 2줄 **"오늘의 복약,"**(`#111`) / **"키핑이 함께 챙겨요"**(`--kp-brand-ink`): 28px/700, 첫 줄 글자 위 y=150, 둘째 줄 y=197(줄 간격 47px), 왼쪽 40px.
- 본문 4줄(14px, `--kp-text-body`, 줄 간격 26px, y=262부터):
  `먹는 약과 영양제를 등록해 보세요.` / `하루 복용 일정을 한눈에 보여주고,` / `믿을 수 있는 자료를 바탕으로` / `꼭 알아야 할 정보도 쉽게 알려드려요.`
- 맨 아래 큰 버튼 **"시작하기"**(민트, 흰 글자, 높이 50, 좌우 16, 완전 둥근 모서리).
### 4-2. 내 정보 저장 안내·동의 (03/04)
- 뒤로 가기 `<`(왼쪽 위). 제목 **"내 정보는 이 기기에만 저장돼요"**(19px/700, y=154), 부제 **"키핑에 등록한 정보는 외부 서버로 보내지 않아요."**(14px, `--kp-text-sub`, y=192).
- 동의 줄(y=245~298, 높이 54, 좌우 16, 모서리 16): 체크박스(20px) + **"내용을 확인하고 모두 동의해요"**(15px/600). 체크 전 줄 배경 `--kp-consent-bg-off`·체크박스 `--kp-disabled-bg`, 체크 후 `--kp-consent-bg`·체크박스 민트(흰 체크).
- 목록 3개(체크 표시는 항목 가운데, 글 15.5px, 글 줄 간격 24px, y=333 / 388 / 464). 체크 전: 글 `--kp-text-body`(첫 줄 `#656565`), 체크 표시 `#BDBDBD`. 체크 후: 글 `#111`(첫 줄 `#2F2F2F`), 체크 표시 민트.
  1. `약과 영양제, 복용 시간이 이 기기에 저장돼요.`
  2. `기기를 바꾸거나 브라우저 데이터를 삭제하면` / `정보가 사라질 수 있어요.`
  3. `키핑은 공식 자료를 바탕으로 정보를 제공하며,` / `의료진의 진단과 치료를 대신하지 않아요.`
- 큰 버튼 **"다음"**: 체크 전 비활성(`--kp-disabled-bg`/`--kp-disabled-text`, 눌러도 아무 일 없음), 체크 후 민트. 동의는 `localStorage`의 `kp:consent`에 저장.
### 4-3. 복약 정보 검색 (05/06/07)
- 맨 위: 뒤로 가기, **진행 바**(x=101~301, 높이 6, 트랙 `--kp-consent-bg`, 채움 민트, 약 60%), 오른쪽 끝 **"건너뛰기"**(14px).
- 제목 2줄 **"복용 중인 처방약을"** / **"검색해서 추가해주세요."**(19~20px/700, y=159, 186), 부제 **"약 이름이나 성분명으로 찾을 수 있어요."**(14px, y=220).
- 검색창(높이 60, 좌우 16, 모서리 ~18, 테두리 1.5px `--kp-field-border`): 왼쪽 돋보기, 안내 글 **"약 이름 및 성분 검색 (예: 메타포르민정)"**. 글을 치면 테두리 `--kp-field-focus`, 오른쪽에 ✕(지우기). **입력 글자는 16px**(7장 참고).
- 결과 줄(검색창 아래, 줄마다 높이 54 간격, 글 15px): 검색어와 같은 앞부분은 **민트로 강조**, 나머지는 `#111`. 줄을 누르면 선택 상태(배경 `--kp-consent-bg`, 모서리 12, 07번). 결과는 기존 약 검색(`dur.search(q, {limit: 40})`)을 `KeepingDrugName.group(결과, {query, limit: 8})`(`js/drugname.js`)로 **함량·괄호를 떼고 같은 이름은 한 줄로 묶어** 시안처럼 짧은 이름만 보여 준다(예: "씬지로이드정", "글리메디정"). 줄을 고르면 그 묶음의 대표(`rep.code`)로 항목을 만든다(함량이 달라도 같은 성분이라 주의 안내는 같다).
- 아래 두 버튼(높이 50): 왼쪽 **"건너뛰기"**(테두리 버튼, 그 아래 작은 글씨 **"언제든 수정할 수 있어요"**), 오른쪽 **"다음"**(민트). 두 버튼 **폭이 같다(각 181px, 시안 이미지 기준)**.
- **다음**: 선택한 결과가 있으면 복용법 입력(4-4)으로, 없으면 다음 온보딩 단계로(기존 앱 순서). **건너뛰기**는 다음 온보딩 단계로.
### 4-4. 복용법 입력 (08)
- 상단: 뒤로 가기(왼쪽), 가운데 제목 **"복용법 입력"**(16px/600).
- 약 카드(좌우 16, 흰 배경, 모서리 16, 그림자 `0 2px 12px rgba(23,25,28,.06)`, 안쪽 여백 14): 왼쪽 46×46 사진 칸(둥근 모서리), 오른쪽 위 **약 이름**(16px/700), 아래 **"약원어명 · 치료부위"** 자리(11px, `--kp-link`). → 실제 값은 7장.
- 구역 3개(구역 제목 15px/700, 칩 줄은 제목 아래 12px, 칩 높이 31·글 13px·좌우 14·칩 사이 8·테두리 `--kp-field-border`·글 `#656565`·완전 둥글게, 구역 사이 ~40px, 왼쪽 31px):
  1. **하루에 몇 번 드시나요?** — `1회` `2회` `3회` `필요 시` `직접 입력`
  2. **언제 드세요?** — `아침` `점심` `저녁`
  3. **식전 / 식후** — `식전` `식후` `식사무관`
- 선택된 칩: 배경 `--kp-consent-bg`, 테두리 민트, 글자 `--kp-brand-ink`.
- **"주의사항"** 줄(좌우 16, 높이 40, 배경 `--kp-consent-bg-off`, 모서리 12): 왼쪽 경고 삼각형 + **"주의사항"**(`--kp-warn`). 누르면 그 약의 `model.detail`의 `general`(약 설명서 안내)을 바텀시트로 보여 준다(아래 4-6과 같은 시트 틀).
- 맨 아래 큰 버튼 **"저장"**(민트).
- **동작**: 횟수는 하나만 선택. 횟수가 `1회/2회/3회/직접`이면 "언제"에서 그 횟수만큼(최대) 고를 수 있다. `필요 시`를 고르면 "언제"는 비활성(흐리게, 눌러도 무반응)이고 시각은 저장하지 않는다. "식전/식후"는 하나만 선택(선택 안 해도 됨). **저장**은 (횟수가 필요 시) 또는 (고른 "언제" 개수 = 횟수)일 때만 활성.
- **`직접 입력`**: 칩이 숫자 입력 칸으로 바뀐다(칩 높이 그대로, 폭 64px, 숫자 키패드, 1~6). 7장 참고.
### 4-5. 저장
- **저장** → 항목에 `times`(고른 시각들), `timesPerDay`, `meal`('before'|'after'|'any'|없음), `prn`(필요 시이면 true)을 넣어 저장하고 **복약 정보 검색(05)** 으로 돌아온다. 담은 약은 유지된다. 알림은 기존 문구 `"{약 이름} 담았어요"`(하단 탭 위 토스트).
- `prn`이면 `times: []`이고 홈 시간선에는 나오지 않는다(내 약 탭에서만 보임, 7장).
### 4-6. 시간 바텀시트 (아침·점심·저녁을 고를 때)
시안에 없는 화면이라 **기존 근거 시트와 같은 틀**을 쓴다(새로 디자인하지 않는다): 뒤 어두운 막 `rgba(0,0,0,.45)`, 흰 시트, 위쪽 모서리 28px, 맨 위 손잡이(40×4), 오른쪽 위 ✕(44px).
- **칩을 누르면**(선택 안 된 칩) 시트가 아래에서 올라온다(0.25초 ease-out). 제목: 누른 칩의 이름 **"아침"** 등(16px/600).
- 내용: **시각 입력 칸** 하나(높이 56, 모서리 16, 글자 **20px/600 가운데**, 기본값 `KeepingTime.DEFAULTS`: 07:30 / 12:30 / 18:30, `inputmode="numeric"`, 열리자마자 포커스·전체 선택). 규칙은 `js/timeinput.js` 그대로: `730`→`07:30`, 잘못 읽으면 기존 문구 `time_invalid`를 입력칸 아래 보조 색 작은 글씨로, 칩과 다른 시간대면 `time_band_hint`.
- 맨 아래 큰 버튼 **"저장"**(민트): 시각이 읽혀야 활성. 누르면 시트가 닫히고 그 칩이 선택되며 칩 글자가 **"아침 07:30"**처럼 시각을 더해 보여 준다(7장).
- ✕, 어두운 막, 아래로 끌기: 닫기. 닫으면 그 칩은 **선택하지 않은 상태 그대로**.
- **선택된 칩을 다시 누르면** 선택이 해제된다(시트는 열리지 않는다). 시각을 고치려면 해제하고 다시 고른다.
- 키보드: 시트가 키보드에 가리지 않게 `visualViewport`로 시트 아래 여백을 올린다. 시트 위쪽은 `max-height: calc(100dvh - var(--kp-safe-top) - 16px)`.
- **같은 시트를 영양제 등록과 기존 "담기 확인"의 시간 선택에도 쓴다**(기존 아코디언 제거). 내 약 탭의 시간 고치기·약봉투의 시간 줄은 지금대로 두되, 시각 입력은 같은 `KeepingTime` 규칙.

## 5. Safari·휴대폰 (이 화면들에 필요한 만큼만)
- 안전 영역: 위 `var(--kp-safe-top)`, 아래 `var(--kp-safe-bottom)`(`css/safari-base.css`가 없으면 없이 `env()`를 직접 쓰되 `max(env(...), 0px)`).
- **입력칸은 16px 이상**(검색창, 시간 입력, 직접 입력 횟수).
- 아래 큰 버튼은 `position: sticky`/`fixed`로 두되 **안전 영역을 비운다**. flex 자식은 `min-width: 0`. 알림은 `transform` 중앙 정렬 대신 `left/right` 여백.
- 스와이프 뒤로 가기: 단계마다 `history.pushState`, `popstate`로 이전 단계 복원, `pageshow`의 `persisted`면 다시 그린다.
