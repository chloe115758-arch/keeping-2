# 키핑 (Keeping)

**먹는 약과 영양제를 등록하면 하루 복약 타임라인을 만들고, 공식 자료(병용금기·약 설명서) 근거가 있는 만큼만 주의를 알려 주는 웹 서비스.**
근거가 없으면 말하지 않는다. 의료 조언이 아니며, 판단은 약사·의료진에게 확인해야 한다.

- 이화여자대학교 디자인대학원 · 차세대 경험디자인 중간평가 프로젝트
- 배포 주소: `https://chloe115758-arch.github.io/keeping-2/`  (정적 사이트, 서버 없음)
- 시연 영상: (링크를 여기에 넣는다)

## 1. 문제와 접근
- **문제**: 처방약과 영양제를 함께 먹을 때 무엇을 조심해야 하는지 알기 어렵다. (설문 52명, 인터뷰 4명)
- **접근**: 사용자가 등록한 약·영양제를 하루 시간표로 만들고, **공식 자료에 근거가 있는 안내만** 시간표 위에 보여 준다.
- **원칙**
  1. 근거 등급은 3단계: ① 공식 지정(병용금기) ② 허가사항(약 설명서) 근거 ③ 근거 없음(말하지 않음)
  2. 복용 중단·용량 변경을 지시하지 않는다. "안전하다", "괜찮다", "드세요" 같은 표현을 쓰지 않는다.
  3. 못 찾은 것은 "없다"가 아니다: "확인한 범위에서 찾은 주의가 없어요"라고만 말한다.
  4. 런타임에 LLM을 쓰지 않는다. 건강정보는 이 기기에만 저장한다(서버로 보내지 않는다).
  5. 앱은 사용자가 누를 때만 시간을 바꾼다("시간을 옮길까요?" 제안).

## 2. 주요 기능
온보딩(스플래시, 저장 안내 동의) → 약 검색·복용법 입력(시간은 바텀시트) → 영양제 검색(성분 약 40개 + 제품 4만 6천 건) → 홈 타임라인
→ 주의 블록과 근거 시트(원문, 출처, 확인일) → 약봉투 화면의 "약 설명서 안내" → 시간 옮기기 제안.
시연 순서는 `docs/demo-scenarios.md`.

## 3. 실행
```bash
# 정적 사이트이므로 아무 정적 서버나 된다
python3 -m http.server 5500          # 또는 VS Code Live Server
```

## 7. 한계 (정직하게)
- **정확도 미측정**: 허가사항 추출의 정밀도·재현율을 표본으로 재지 않았다. 그래서 "정확하다"고 말하지 않고 원문을 함께 보여 준다.
- **확인 범위**: 허가사항 규칙은 수집한 성분 범위 안에서만 있다. 범위 밖 약은 "확인 범위 밖"으로 알린다.
- **영양제는 성분 기준**: 제품의 원재료 글자에서 성분을 찾는다. 원재료가 짧게 적힌 제품은 성분을 못 찾을 수 있다.
- **"필요 시" 약**은 시각이 없어 홈 시간표에 나오지 않는다.
- **휴대폰(iPhone Safari) 확인이 충분하지 않다.** 데스크톱 Chrome 기준으로 만들었다.
- **처방전·약봉투 인식은 시연 수준**이다(실제 인식 서비스가 아니다).
- 법률·의료기기 해당 여부와 데이터 이용 조건 일부는 검토하지 못했다.

## 8. AI 활용 과정
Claude(설계, 데이터 수집·가공, 엔진, 시험, 문구, 설명서)와 Claude Code(화면 구현)를 역할을 나눠 썼다. 사람이 결정(원칙, 디자인 시안, 문구)하고, AI는 근거 있는 값(시안 이미지의 픽셀, 공식 데이터)으로 만들고 **스스로 만든 오류를 시험으로 잡았다.**
- 영양제를 골라도 주의가 안 뜬 버그: 진단 도구(`scripts/diagnose_scenario.js`)로 원인 확정(원재료가 "목록 글자"일 때 성분을 못 찾음) 후 수정
- 시안과 일치율 97%인데 글자 크기가 15% 틀려도 통과하는 문제를 실험으로 확인하고 띠 비교 추가(`tests/ui-diff.py`)
- "술"이 "수술" 안에서 잡히는 오탐, 조사(은/는) 오류, 금지 표현("드세요")을 자동 검사로 방지
- 비밀 값이 공개 저장소 기록에 올라간 것을 점검 스크립트로 발견하고 대응(`scripts/prepush_check.py`)
- AI 자신의 추정이 틀린 사례도 기록했다(글자 크기 역산 19.5px → 실제 22px)

## 9. 라이선스·유의
코드는 학교 과제용 프로토타입이다. 병용금기 데이터는 공공저작물이며 출처 표시가 필요하다. Pretendard는 SIL OFL 1.1.
